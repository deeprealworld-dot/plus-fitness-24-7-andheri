# Plus Fitness 24/7 Andheri

Approved premium redesign for the Plus Fitness 24/7 Andheri multipage website.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Deploy to Vercel

- Import the repository into Vercel.
- Leave **Root Directory** blank (or set it to `.`).
- Use the detected Next.js settings.
- Keep `package-lock.json`; do not add a separate `pnpm-lock.yaml`.

The website includes the home page, About, Programs and program details, Memberships, Trainers, Gallery, Reviews, FAQ, Contact, Careers, and Privacy pages.
